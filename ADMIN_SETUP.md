# Настройка базы и админки

Ниже пошаговая схема для сайта `https://globaledtech-kz.vercel.app/`.

Теперь логика такая:

- форма регистрации сохраняет заявки в базу данных
- админка открывается отдельно по адресу `/admin`
- Google Sheets больше не используется

## Что уже сделано в коде

В проекте уже подготовлено:

- API для сохранения регистрации
- API для просмотра списка регистраций
- страница админки
- вход в админку по паролю

Вам остается только подключить базу в Vercel и задеплоить обновленный проект.

## Шаг 1. Создайте базу данных в Vercel

1. Откройте `Vercel`.
2. Выберите проект `globaledtech-kz`.
3. В верхнем меню откройте `Storage`.
4. Нажмите `Create Database`.
5. Выберите `KV`.
6. Подтвердите создание базы.

После создания Vercel покажет переменные окружения для базы.

Нужны две:

- `KV_REST_API_URL`
- `KV_REST_API_TOKEN`

Часто Vercel сам предлагает сразу привязать их к проекту. Если предложит, соглашайтесь.

## Шаг 2. Добавьте пароль для админки

1. В проекте Vercel откройте `Settings`.
2. Перейдите в `Environment Variables`.
3. Добавьте новую переменную:

`ADMIN_PASSWORD`

Пример значения:

`GlobalEdTechAdmin2027!`

Это пароль, который вы будете вводить при входе в админку.

## Шаг 3. Проверьте env-переменные

В проекте должны быть:

- `KV_REST_API_URL`
- `KV_REST_API_TOKEN`
- `ADMIN_PASSWORD`

Если какой-то из них нет, регистрация работать не будет.

## Шаг 4. Задеплойте обновленный код

После добавления переменных нужно сделать новый деплой.

Если проект связан с GitHub:

1. Загрузите изменения в репозиторий.
2. Vercel сам начнет новый deployment.

Если хотите вручную:

1. Откройте `Deployments`.
2. Найдите последний deployment.
3. Нажмите `Redeploy`.

Важно:

Если не сделать redeploy после добавления env-переменных, сайт будет продолжать работать со старой конфигурацией.

## Шаг 5. Как проверить регистрацию

После деплоя:

1. Откройте сайт
   `https://globaledtech-kz.vercel.app/`
2. Заполните форму регистрации.
3. Нажмите `Отправить заявку`.

Если все настроено правильно, форма отправится без ошибки.

## Шаг 6. Как открыть админку отдельно

Админка открывается по адресу:

`https://globaledtech-kz.vercel.app/admin`

Там будет форма входа.

Введите значение из переменной:

`ADMIN_PASSWORD`

После входа вы увидите:

- дату регистрации
- имя
- фамилию
- email
- телефон
- компанию
- формат участия

## Шаг 7. Как работает хранение

Каждая новая заявка сохраняется в базе Vercel KV как отдельная запись.

Админка читает эти записи и показывает их списком.

## Шаг 8. Что делать, если снова ошибка

Если регистрация снова не отправляется:

1. Откройте `Vercel -> Project -> Functions`.
2. Выберите `api/registrations`.
3. Откройте `Logs`.
4. Посмотрите текст ошибки.

Самые частые причины:

- не создана база `KV`
- не добавлены `KV_REST_API_URL` и `KV_REST_API_TOKEN`
- не добавлен `ADMIN_PASSWORD`
- после добавления переменных не сделан `Redeploy`
